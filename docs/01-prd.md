# MVP 제품 요구사항

## 사용자 시나리오

1. 방문자는 홈에서 서비스의 목적, 누적 회차·글·멤버 수와 최신 기록을 파악한다.
2. 검색어와 작성자·태그·주제 필터를 조합해 글을 좁힌다. 조건은 URL 쿼리에 남는다.
3. 회차 번호를 열어 해당 모임의 모든 발표 슬롯을 공유한다.
4. 작성자를 열어 시간순으로 축적된 개인의 학습 궤적을 본다.
5. 게시된 글은 새 탭에서 원문으로 이동한다. 미작성 슬롯은 링크 없이 상태만 전달한다.

## 기능 요구사항

- 회차는 최신순, 멤버 기록은 오래된 순으로 정렬한다.
- 검색은 제목·태그를 대상으로 하며 한글과 영문 대소문자를 구분하지 않는다.
- 작성자와 태그는 각각 단일 선택이며 검색어와 AND 조건으로 결합한다.
- 태그는 원문 표기를 유지하고 웹에서 여섯 주제로 묶는다. 글의 태그와 주제는 각각 관련 기록으로 이동하는 링크다.
- 적용 중인 조건은 개별 제거할 수 있고 `topic`을 포함한 모든 필터는 공유 URL에서 복원된다.
- 주제별 직접 접근 URL과 게시 글을 최신순으로 제공하는 RSS 피드를 제공한다.
- 초기화는 모든 조건을 제거한다. 결과가 없으면 명확한 빈 상태를 표시한다.
- 외부 링크는 `target="_blank"`, `rel="noopener noreferrer"`를 사용한다.
- 360px부터 가로 스크롤 없이 사용할 수 있고 키보드 포커스가 항상 보인다.
- 루트, 소개, 회차, 멤버 페이지마다 고유한 제목과 설명을 제공한다.

## 완료 기준

형식 검사, 타입 검사, 단위 테스트, 프로덕션 빌드, 핵심 경로 E2E와 시각 검수를 통과하면 MVP 완료로 본다.
