# 콘텐츠 및 도메인 명세

단일 원본은 `Frontend-Archive/archive` 저장소의 `archives/YYYYMM.md`다.

## 원본 규칙

- 파일명 연·월은 `date`와 일치한다.
- `id`는 1부터 증가하며 중복될 수 없다.
- `title`은 `스터디 {id}회차`다.
- `type`은 `on-line` 또는 `off-line`이다.
- 발표자는 권시현 → 민준경 → 염승준 → 최승원 순서로 네 명 모두 존재한다.
- 미작성 슬롯은 `title`, `url`, `tags`를 함께 비운다. 일부만 빈 상태는 허용하지 않는다.

파싱 실패, 스키마 위반, 중복 ID, 잘못된 파일명은 빌드 실패로 처리한다. 화면에서 조용히 제외하지 않는다.
