# 정보 구조 및 디자인

## 정보 구조

- `/`: 제품 소개, 누적 현황, 검색·필터, 회차 타임라인, 멤버 소개
- `/sessions/[id]`: 한 회차의 날짜·진행 방식·발표 슬롯
- `/members/[slug]`: 한 멤버의 오래된 순 학습 기록
- `/about`: 문제의식, 운영 방식, 데이터 원본

검색 상태는 `q`, `author`, `tag` 쿼리로 표현한다.

## 디자인 원칙

- 따뜻한 종이색, 짙은 잉크색, 단일 코발트 블루로 에디토리얼 인상을 만든다.
- 큰 제목과 회차 번호, 긴 호흡의 여백으로 시간의 축적을 표현한다.
- 본문과 제어 요소는 산세리프, 제목과 숫자는 세리프 계열을 사용한다.
- 모션은 의미 있는 호버와 진입에만 쓰고 reduced motion 환경에서는 제거한다.
- 색만으로 상태를 구분하지 않고 텍스트 레이블을 함께 제공한다.
